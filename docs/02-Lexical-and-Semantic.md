# Lexical, semantic and hybrid retrieval

**Lexical retrieval:** finding information through matching words and tokens.

**Semantic retrieval:** finding information through similarity between learned representations of text meaning.

**Hybrid retrieval:** combining lexical precision with semantic similarity.

The last is particularly important for document intelligence and RAG (retrieval-augmented generation) systems. Lexical retrieval protects exact identifiers, file names, technical terms and numbers; semantic retrieval finds relevant information expressed in different words.

**In short:** lexical = what the text says; semantic = what the text means (approximately, as the embedding model represents it).
